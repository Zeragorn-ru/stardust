# Редизайн админки — спека и правила

Полная переработка UI с нуля. Слой данных (`api.ts`, `types.ts`, `format.ts`,
`fileUtils.ts`, хуки) сохранён — меняется весь визуальный и интерактивный слой.

## Принципы

1. **Унификация.** Каждый экран собран только из общих примитивов (`src/ui`).
   Своего CSS у экранов нет, кроме редких фиче-блоков в `styles.css` (раздел
   «Фиче-блоки»). Одинаковое: отступы, радиусы, таблицы, тулбары, пустые
   состояния, модалки, тосты.
2. **Строгость.** Плотная модульная сетка (шаг 4px), единый масштаб типографики,
   одна высота строки таблицы, одна высота контрола (36px, компакт 30px).
3. **Без визуальных багов.** Никаких хаков поверх хаков: состояния hover /
   focus-visible / disabled / loading обязательны у каждого примитива;
   переполнения управляются (`min-width: 0`, ellipsis), скроллы локальные.

## Дизайн-токены (theme.css)

- Фон: `#12141f` (ночной сине-индиговый), поверхности `#181b29` / `#1e2233`,
  границы `#2b3048`.
- Текст: `#e8eaf2`, приглушённый `#9298b3`.
- Акцент — «звёздное золото» `#f0c979` (бренд StarDust), hover `#f6d68f`;
  семантика: успех `#7fd6a4`, опасность `#ef8a8a`, инфо `#8fb7e8`.
- Моно-шрифт (ui-monospace/JetBrains Mono) для путей, sha1, версий, id.

## Примитивы (src/ui)

Button, IconButton, Input, Select, Textarea, Switch, Field (label+control+hint),
Panel (заголовок+действия+тело), Table (thead/tbody, sticky header),
Tabs, Modal (+ConfirmDialog), Badge/Chip, Toast (feedback), Spinner,
EmptyState, ErrorPanel, StaleBanner, ProgressBar, StatTile, Toolbar,
PageHeader, CopyButton, Tooltip.

Правила:
- Кнопка-действие раздела — одна «primary» на экран; деструктив всегда
  подтверждается ConfirmDialog.
- Таблицы: плотные, действия справа, текст ячеек с ellipsis + title.
- Формы: только через Field; ширина полей из сетки, не инлайн-магия.
- Пустое состояние — всегда EmptyState с действием, а не пустой div.

## Оболочка (src/shell)

Сайдбар (240px, группы из navConfig, свёртывание) + топбар (заголовок раздела,
описание, контекстные действия) + content. Один адаптивный app: < 960px
сайдбар превращается в drawer; отдельного мобильного приложения больше нет
(точка входа `/m` удалена).

## Экраны и их состав (все существующие функции сохранены)

- **Обзор** — телеметрия сервера (онлайн, TPS, MSPT, средний онлайн),
  последние события join/quit, статусы бэкапов/синка/релизов, быстрые действия.
- **Сборки** — список (активная помечена), создание, клон, удаление,
  активация, проверка build-check/deps-check; **детали сборки**: дерево файлов,
  загрузка с прогрессом, редактор текстовых файлов (dirty-guard), профили
  опциональных модов, поиск и установка модов (Modrinth/CurseForge) с
  зависимостями, sync на SFTP-панель (host-key подтверждение), скачивание папки
  архивом, patch-метаданных файлов.
- **Настройки** — Telegram, SFTP (+сброс fingerprint, sync статистики),
  бэкапы (S3-совместимые + пароль, ручной запуск, статус), награда монет,
  GitHub-токен, AI-анализ крашей (вкл/выкл, endpoint, модель, ключ, тест),
  CurseForge-ключ, токен телеметрии.
- **Аккаунты** — поиск/фильтры, rename, роли, бан/разбан (длительность,
  причина), сброс пароля, Telegram unlink/set, статистика, скин (загрузка,
  модель, превью 3D/головы), карточка игрока (бейджи/градиенты, активные).
- **Кастомизация** — CRUD бейджей и градиентов.
- **Новости / Гайды** — список + редактор (маршруты `/news/:id`, `/guides/:id`),
  dirty-guard, markdown-превью, pin/published, слаг/категория у гайдов.
- **Логи** — журнал событий сервера, детали, AI-анализ краша (запуск/статус).
- **Внешние моды** — allowlist (modId+jar+sha256) и block-правила.
- **Сезоны** — список, активный сезон, архивация (фоновая задача).
- **Релизы** — релизы GitHub, каналы beta/stable, CI-прогоны по платформам,
  promote и set-latest (фоновые задачи).

## Сквозные механизмы (сохраняются)

Логин + Telegram 2FA (poll), dirty-guard редакторов, тосты, контекстное меню,
SFTP host-key подтверждение, фоновые задачи (202 + polling), stale-chunk reload,
useAsyncData (poll с паузой на скрытой вкладке).
