# Performance baseline

`make performance-baseline` выполняет локальный замер трёх frontend-приложений и release-сборки backend-крейтов.

Измеряются:

- время `npm run build` для `launcher`, `admin-web` и `website`;
- размер каталога `dist` в байтах и количество файлов в нём;
- время `cargo build --release -p auth-server -p admin-server -p telegram-bot`.

Перед запуском frontend-сборок нужны установленные зависимости (`npm ci` в соответствующем каталоге). Приложение без `node_modules` пропускается с явной отметкой `skipped`.

## Ограничения

Это инструмент для сравнений на одной машине, а не воспроизводимый benchmark. Результаты зависят от ОС, CPU, диска, версии Node/Rust, состояния npm/Cargo-кэшей и содержимого рабочей копии. Скрипт печатает окружение и timestamp, чтобы эти условия можно было учитывать.

Frontend build получает время от начала до завершения команды `npm run build`; `dist_bytes` — размер файлов каталога по `du -sk`, округлённый до KiB, а `dist_files` — число обычных файлов. Размеры не являются размером сжатого deploy-архива.

Backend измеряется только по времени команды. Скрипт не утверждает, что бинарники были пересобраны с нуля: Cargo может использовать инкрементальные или уже готовые артефакты. Если сборка не завершается успешно, результат помечается как `failed`, а сам скрипт продолжает выполнение и сообщает это явно.

Команда возвращает успешный статус после завершения всех измерений, даже если отдельная сборка завершилась ошибкой, чтобы baseline можно было собрать частично. Ошибку нужно проверять по полю `status` и выводу Cargo.
