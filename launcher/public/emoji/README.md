# emoji — SVG-пак Minecraft-совместимых эмодзи

186 SVG-иконок эмодзи, которые корректно отображаются в чате и на табличках
Minecraft. Сгенерировано скриптом `scripts/gen-emoji-svg.mjs` — руками файлы
не редактировать: перегенерация перезапишет.

## Зачем

В админке есть бейджи игроков с эмодзи (`CustomizationView`) и другие места,
где эмодзи нужно показать так, как его увидят в игре. Системные эмодзи-шрифты
браузера рисуют `☠` или `☀` совсем не так, как Minecraft, — игрок не понимает,
что реально попадёт в чат. Этот пак даёт пиксельные версии глифов «как в игре»
плюс символы для вставки в чат.

## Состав

| Файл | Назначение |
| --- | --- |
| `emoji-<slug>.svg` | Одна иконка: `<path>` с точным пиксельным контуром глифа, `viewBox="0 0 9 8"`, `fill="currentColor"` — цвет наследуется от текста, работает в тёмной теме |
| `manifest.json` | Полный индекс: символ, codepoints, имя, слаг, файл, тир |
| `emoji.css` | Классы `.mc-emoji-<slug>` с `background-image` и CSS-переменной `--mc-emoji` (символ для вставки) |
| `../src/emoji/index.ts` | Типизированный индекс для React: `MC_EMOJI`, `MC_EMOJI_NATIVE`, `findMcEmoji(char)` |

Три тира:

- **native (44)** — эмодзи, которые с 1.20.2 рисует сам шрифт Mojangles
  (Minecraft.wiki): ☀ ☁ ☂ ☃ ☄ ☑ ☔ ☠ ☮ ☯ ☹ ☺ ♀ ♂ ♠ ♣ ♥ ♦ ⚓ ⚔ ⚗ ⚠ ⚡ ⛄ ⛈ ⛏
  ✉ ✔ ❣ ❤ ❄ 🔥 🌊 🗡 🏹 🪓 🔱 🎣 🧪 ✂ 🍖 🪣 🔔 ⏳. Именно так они выглядят в игре.
- **extra (139)** — остальные символы старого gist-списка «Minecraft allowed
  emojis» (шахматы, знаки зодиака, стрелки, ноты, цифры, `#`, `*`…). В
  современных версиях игры (26.x, у нас 1.21.1) они тоже есть в шрифте и
  извлечены тем же способом. В старых версиях их рисовал Unifont-фолбэк.
- **text (3)** — `〰` (Wavy Dash), `㊗` и `㊙`: в шрифте Mojangles их нет,
  поэтому это SVG с `<text>` и fallback-цепочкой шрифтов. Рендер зависит от
  системы — честно фиксируем этот компромисс. Символ для вставки в чат
  всё равно лежит в `manifest.json` / `index.ts`.

## Откуда геометрия

Скрипт читает шрифт **Mojangles / Minecraft Default Regular 26.2**
(`26.2-Minecraft-Regular.otf`, источник: `archive.org/details/minecraft-seven`)
и разбирает его CFF-таблицу без внешних зависимостей: `cmap` → `CharStrings`
→ интерпретатор Type 2 charstrings → полигоны глифов. Все 186 глифов
проверены: в charstrings встречаются только `rmoveto`, `hmoveto`, `vmoveto`,
`rlineto`, `hlineto`, `vlineto` — кривых и subr-вызовов нет, шрифт
действительно пиксельный. Результат сверен с независимым разбором TTF-версии
того же шрифта (таблица `glyf`) — контуры совпадают.

Система координат: EM 1024 юнита = 8 «пикселей» глифа по 128 юнитов;
в SVG 1 юнит = 1 пиксель, `viewBox="0 0 9 8"` (9 колонок — максимально
широкий глиф; узкие глифы центрируются по горизонтали). Заливка —
`fill-rule="evenodd"`: «дырки» в черепе, песочных часах и т.п. — это
вложенные контуры.

## Использование

```tsx
import { MC_EMOJI_NATIVE, findMcEmoji } from "../emoji";

// все «настоящие» эмодзи Minecraft — для пикера
{MC_EMOJI_NATIVE.map((e) => (
  <img key={e.slug} src={`/${e.file}`} alt={e.name} width={18} height={18} />
))}

// символ для вставки в чат (то, что реально уйдёт в Minecraft)
const emoji = findMcEmoji("❤")?.char;
```

SVG красятся через `currentColor`: оберните в элемент с нужным `color`.
Тир `text` рендерится системным шрифтом — внешнего вида как в игре нет.

## Регенерация

```sh
# шрифт кладём в third_party/fonts/ (или /tmp/mc-emoji-src/), источник — см. выше
node scripts/gen-emoji-svg.mjs [--font <path.otf>] [--source /tmp/mc-emojis.txt]
```

Зависимостей нет — только встроенные модули Node 20+.

## Ограничения и v2

- Пак повторяет метрики одиночных глифов; составные последовательности
  (ZWJ, модификаторы тона кожи) в Minecraft не поддерживаются — их и в
  списке-источнике нет.
- `viewBox="0 0 9 8"` (не квадрат): при выводе в квадратном контейнере
  `preserveAspectRatio` центрирует иконку — пиксели остаются чёткими при
  кратных размерах (16/32/64… для 9x8 фактический масштаб 64/9).
- **v2, если понадобится строгая юридическая чистота**: перерисовать 44
  native-глифа вручную по 8×8-сеткам (контуры в SVG — уже почти
  пиксель-арт, редрафт механический), вместо извлечения из шрифта. Либо
  ограничиться глифами, чья форма тривиально выводима из геометрии
  (квадраты-сердца, шахматные фигуры).
- Проверка целостности: 186 сгенерированных SVG соответствуют 186 записям
  `manifest.json` (165 из gist + 21 native-эмодзи 1.20.2+; 3 из них
  отсутствуют в шрифте и помечены `text`).
