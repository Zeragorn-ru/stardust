# StarDust Launcher — UX/UI улучшения

## Приоритет 1 (критично)

### 1. ✅ Кастомизация — фон
Градиент на overlay, glow по краям модалки, внутренний градиент на фоне.

### 2. ✅ Кнопка retry при ошибке
`.btn--play-retry` — нейтральный glass стиль, без зелёного.

### 3. ✅ Login — двойной glass в approval state
Убраны стили `.login__form` у вложенной формы.

### 4. ✅ Анимации выключены — instant transitions
При `data-motion="off"`: быстрые transition (0.1s), backdrop-filter отключен, stagger мгновенный.

### 5. ✅ Производительность — SkinViewer3D idle
Автопауза рендера при потере фокуса или 8с бездействия мыши.

## Батч 2 — багфиксы и полировка (аудит 51 агентом, 37 подтверждённых багов)

### 24. ✅ ConfirmDialog вместо window.confirm (критично, macOS)
WKWebView в wry не реализует runJavaScriptConfirmPanelWithMessage — все 5 window.confirm в настройках молча возвращали false на macOS («Изменить папку», «Вернуть стандартную папку», Escape при isDirty, «Глубокий поиск», «Сбросить настройки»). Новый `components/ConfirmDialog.tsx` (promise-based, .modal-overlay/.modal, Escape → false, danger-вариант) + стили `.confirm-modal`.

### 25. ✅ Escape на экране новостей
Escape закрывал весь лаунчер (Windows) — теперь возвращает на главный экран.

### 26. ✅ Отклонённое обновление не навязывается
dismissedUpdateVersion ref: плановый 30-минутный опрос не переоткрывает отвергнутую версию.

### 27. ✅ Скин-превью: гонка загрузок
SkinViewer3D: асинхронные загрузки сериализованы через skinChainRef — медленный стейл-промис не перезаписывает новый скин.

### 28. ✅ SkinModal: повторный выбор того же файла
e.target.value сбрасывается после чтения FileList — выбор того же PNG снова вызывает onChange.

### 29. ✅ Ошибка сохранения бейджа/градиента видна
NickCustomizer показывает inline-ошибку вместо молчаливого игнорирования.

### 30. ✅ useDelayedUnmount: отмена rAF
requestAnimationFrame теперь отменяется симметрично с setTimeout — модалка не «залипает» видимой при быстром open→close.

### 31. ✅ Клавиатурный фокус в лаунчере
:focus-visible для кнопок, вкладок, свитчей, java-карточек, ник-опций, window-btn (ранее индикатор был только у полей ввода).

### 32. ✅ prefers-reduced-motion отслеживается живьём
watchSystemMotion(): пока пользователь не сделал свой выбор, смена системной настройки мгновенно применяется (data-motion).

### 33. ✅ Ник обновляется после кастомизации
CustomizeModal.onNickSaved → MainScreen подтягивает свежий профиль: бейдж/градиент сразу видны на главном экране.

### 34. ✅ Тексты без жаргона
«status sample» → человеческое описание; «Сервер недоступен» (бан) → «Доступ к серверу ограничен»; «недоступен» при первом пинге → «проверяем…»; ГиБ/МБ → единые МБ; код сброса пароля явно «из Telegram»; онбординг-ошибка выбора папки не падает unhandled.

### 35. ✅ Логи: поиск переживает авто-refresh
Позиция совпадения сбрасывается только при новом запросе, а не при каждой перезагрузке лога; выход курсора за пределы — клампится.

### 36. ✅ Настройки: гварды фоновых операций
Escape при скачивании Java / установке обновления / переносе папки показывает осмысленный диалог вместо тихого ухода.

### 37. ✅ a11y: aria-pressed у выбора бейджа/градиента, имя у свитчей модов

## Батч 2 — админка (admin-web)

### 38. ✅ Enter в ConfirmDialog не подтверждает автофокусную «Отмену»
Глобальный Enter-обработчик игнорирует Enter, когда фокус на кнопке.

### 39. ✅ 401 разлогинивает
api.ts: onAuthRejected (сброс токена + событие auth-expired) в request() и XHR-загрузке; AuthProvider подписан. Logout не «запирает» в вошедшем состоянии при недоступном сервере (try/catch).

### 40. ✅ Деплой мода: опрос без утечек
deployPollRef + unmount-cleanup + 5 попыток при сетевых сбоях (ранее один сбой молча убивал опрос). «mod-v*» → «stardust-mod» в тексте подтверждения.

### 41. ✅ «Сделать активной» — с подтверждением
Оба интерфейса (desktop/mobile) показывают диалог с именем сборки и числом файлов.

### 42. ✅ Dirty-гварды форм
EditBuildModal (desktop+mobile), CreateBuildForm, FileSettingsDrawer: закрытие по Escape/подложке/«Отмена» спрашивает подтверждение при несохранённых изменениях. Dirty и busy читаются через ref (без стейл-клоужеров в window-обработчиках); сравнение полей — со скобками вокруг `(x.trim() || null)` (прецедентность `||` vs `!==`).

### 43. ✅ Ошибка загрузки сборки ≠ «не найдено»
404 → «Сборка не найдена», прочие ошибки → панель с «Повторить» (desktop + mobile).

### 44. ✅ Клонирование с busy-гвардом (mobile)
Кнопка блокируется на время запроса, текст «Копия…».

### 45. ✅ Пароль в карточке игрока скрыт
type="password" + autoComplete="new-password" (ранее вводился открытым текстом).

### 46. ✅ Причина бана видна
Строка «Причина бана» в InfoTab; бан-бейдж в таблице аккаунтов показывает причину inline, а не только в tooltip.

### 47. ✅ Вкладка «Бейджи»: ошибка вместо вечного спиннера
BadgesTab различает загрузку и сбой API (кнопка «Повторить»).

### 48. ✅ «Снять права админа» с себя заблокировано
isSelf прокидывается в PlayerCardModal из AccountsView (selfUuid уже нормализован).

### 49. ✅ Единый formatPlaytime
Общая реализация в format.ts (ранее «45с» в таблице vs «45 с» в карточке).

### 50. ✅ «Синхр. статистики» обновляет таблицу
syncStats() перезагружает данные — колонки «В игре»/«Последний вход» сразу свежие.

### 51. ✅ Загрузка папок >100 файлов
FileUpload: readEntries циклом (WebKit отдаёт максимум 100 записей за вызов) — большие папки больше не теряют хвост.

### 52. ✅ PromptDialog: защита от двойного сабмита
Асинхронный submit с busy-состоянием — двойной Enter не создаёт два файла.

### 53. ✅ Чипы фильтров доступны скринридеру
aria-label «Убрать фильтр: …» на всех 10 кнопках «×».

### 54. ✅ .spin определён
Класс использовался в 4 файлах, но не был определён — теперь анимация вращения иконок реально работает.

### 55. ✅ «Ещё» не рендерится мёртвой на десктопе
Базовые правила .mobile-more/.fm-actions-secondary перенесены из mobile.css в styles.css; media-блок переключает только мобильный вид.

### 56. ✅ SkinHead: shimmer не висит вечно при ошибке
Ошибка загрузки скина переключает на буквенный плейсхолдер.

### 57. ✅ Токен телеметрии копируется одной кнопкой
Кнопка «Копировать» рядом с output; фокус-выделение сохранено.

### 58. ✅ FAB не перекрывает последнюю карточку
m-screen--fab: нижний отступ 76px + safe-area на экране сборок.

### 59. ✅ Русские надписи вместо английских
Eyebrow'и «Player directory», «Cosmetics studio», «Server activity», «Launcher feed», «Modpack pipeline», «Control room» и т.п. переведены; MetricCard «online/offline/ready/setup» → «подключен/готов…»; topbar показывает имя админа вместо статичной «Сессия активна»; «ПК»/«Телефонная версия» унифицированы.

### 60. ✅ Hex-цвета бейджей/градиентов валидируются
isHexColor в модалках кастомизации — кнопка «Сохранить» неактивна для невалидного hex.

### 61. ✅ Тосты-ошибки — role=alert
Скринридеры анонсируют ошибки (ранее все тосты были role=status).

### 62. ✅ Dropzone доступен с клавиатуры
role=button + tabIndex + Enter/Space открывают выбор файлов.

### 63. ✅ Профили модов: пресеты «Производительность»/«Качество» в одной сборке
Одна сборка + список профилей (`build_mod_profiles`), у опциональных модов — метка принадлежности (`profiles`, пусто = «общий»). Лаунчер: карточки-переключатели профилей и бейджи принадлежности в списке модов; админка: диалог управления профилями и чипы в свойствах файла. Переключение = вкл/выкл группы модов через `.dis`-переименования, без перекачки.

### 64. ✅ Статичный фон «звёздная пыль» в лаунчере
Три prerendered-слоя (две туманности + звёздные поля box-shadow с детерминированным PRNG): без JS-анимаций, уважает prefers-reduced-motion, почти бесплатно для GPU.
